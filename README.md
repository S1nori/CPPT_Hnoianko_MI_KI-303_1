# Лабораторна робота № 1 — Реєстр студентів (Варіант 6)

## Призначення
Консольна Java-програма для зчитування реєстру студентів із CSV-файлу, перевірки коректності записів, обчислення агрегованих показників та формування звіту в консоль і текстовий файл.

## Формат вхідних даних (`data/input.csv`)
Кодування файлу — `UTF-8`, один запис на рядок, роздільник полів — крапка з комою (`;`), без рядка заголовків:

```text
name;group;course;average;scholarship
```
* `name` (`String`) — прізвище та ім'я студента (непорожній рядок);
* `group` (`String`) — шифр академічної групи (непорожній рядок);
* `course` (`int`) — номер курсу (додатне ціле число);
* `average` (`double`) — середній бал (невід'ємне число з крапкою, наприклад `87.5`);
* `scholarship` (`boolean`) — ознака отримання стипендії (`true` або `false`).

### Обчислювані показники
1. Кількість коректних записів;
2. Середній бал студентів;
3. Найбільший середній бал;
4. Кількість студентів, які отримують стипендію.

## Збірка та запуск

### Перевірка, тестування, статичний аналіз і пакування
На Windows:
```powershell
.\mvnw.cmd clean verify package
```

На macOS та Ubuntu:
```bash
./mvnw clean verify package
```

### Запуск зібраного JAR
```bash
java -jar target/lab01-1.0.0.jar --version
java -jar target/lab01-1.0.0.jar --help
java -jar target/lab01-1.0.0.jar
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/report.txt
```

## Приклад результату роботи
Для стандартного набору `data/input.csv` (4 коректні та 2 хибні записи):
```text
=== Звіт: Реєстр студентів ===
Показник                       Значення
Коректних записів:                    4
Середній бал:                     84.50
Найбільший бал:                   92.00
Кількість стипендіатів:               2
Помилок обробки: 2
 - Рядок 5: числове поле має помилковий формат
 - Рядок 6: порожнє обов'язкове текстове поле (група або ПІБ)
```
