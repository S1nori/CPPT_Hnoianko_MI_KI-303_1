# Реєстр студентів (Варіант № 6)

Консольний Java-проєкт для зчитування, валідації та статистичного аналізу записів реєстру студентів із використанням інкапсульованого класу-сутності `Student` та допоміжного незмінного типу `GradeScholarship`.

## Архітектура та сутності
* **`Student`** — незмінний (`final`) клас-сутність із полями `private final`:
  * `name` (`String`) — ПІБ студента (не порожнє);
  * `group` (`String`) — шифр академічної групи (не порожній);
  * `course` (`int`) — номер курсу (`> 0`);
  * `average` (`double`) — середній бал (`>= 0`, скінченне число);
  * `scholarship` (`boolean`) — наявність стипендії (`true` або `false`).
  * Конструктор перевіряє всі інваріанти, статичний фабричний метод `Student.fromCsv(String)` розбирає CSV-рядок, а `toString()` форматує запис із використанням `Locale.ROOT`.
* **`GradeScholarship`** — незмінний `record(double average, boolean scholarship)` для передавання оцінки та ознаки стипендії до модуля обчислень.
* **`DataValidator`** — перетворює вхідні рядки у список об'єктів `List<Student>` та збирає повідомлення про помилки із номерами рядків.
* **`StudentReportService`** — обчислює чотири показники варіанта за списком `Student` і формує звіт.

## Формат вхідних даних (`data/input.csv`)
Кодування: `UTF-8`, роздільник полів: `;`, формат рядка:
`name;group;course;average;scholarship`

Приклад:
```text
Іван Петренко;КІ-301;3;87.5;true
Марія Коваль;КІ-302;3;92.0;false
